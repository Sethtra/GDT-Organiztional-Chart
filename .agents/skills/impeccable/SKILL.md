# Impeccable UI Skill

Use Impeccable tools and conventions to design, critique, and polish web applications.

## Workflows & Commands

1. **Anti-pattern Audit**:
   Run `npx impeccable detect` in the project root to scan for design anti-patterns, visual hierarchy issues, color contrast failures, and spacing flaws.

2. **Surface Brief Specs**:
   Always check `.impeccable/` for surface briefs (e.g. `test-landing-surface-brief.md`) and mockups (`.impeccable/mocks/`).

3. **Key Impeccable Commands**:
   - `npx impeccable detect`: Run UI anti-pattern detection
   - `npx impeccable help`: View available Impeccable commands
