## Working notes for Claude

- Windows; several files use CRLF. Prefer the Edit tool over inline shell
  scripts, and never pipe `cat` without input in Bash.
- `npm run db:rollout` **applies** changes; `npm run db:rollout:check` is the dry run.
- New migration → append to `scripts/migration-manifest.json` with the next
  free version, wrapped in `BEGIN;`/`COMMIT;`, and safe to re-run.
- The browser Supabase client uses PKCE. Invite links must use the
  `token_hash` flow (`verifyOtp`), never the default `#access_token` link.
- AGENTS.md: no `git add`/`commit`/`push` without explicit permission.
